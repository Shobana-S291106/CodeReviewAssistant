# AI Code Review Assistant

An AI-powered code review assistant that combines static analysis and Large Language Models to detect silent bugs, logic errors, resource leaks, edge cases, and provide human-readable explanations.

## Features

- Static Code Analysis
- AST Parsing
- Silent Bug Detection
- AI Explanations
- Code Suggestions
- Multi-language Support (Future)

## Tech Stack

Frontend: React

Backend: Spring Boot

AI Service: FastAPI

Parser: Tree-sitter

LLM: Gemini API

Database: PostgreSQL
